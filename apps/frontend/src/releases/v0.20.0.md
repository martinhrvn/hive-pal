# Version v0.20.0 Swarm Season

**Released:** Unreleased

## 🚀 What's New

### All Apiaries View

- **"All apiaries" in the apiary switcher** — see hives, inspections, todos, queens and harvests across every apiary you own or belong to, with the dashboard grouped per apiary; writes still target one concrete apiary, and editing a hive from another apiary works from the all-apiaries view (PR #215)
- **Works across the whole app** — hives, inspections, photos, audio and AI results, todos, queens and hive actions all load and save from the all-apiaries view, and the backend now treats the selected apiary as a filter rather than a requirement
- **Files, calendar, batch inspections and the activity timeline** now span all apiaries in the all-apiaries view, with the apiary shown on files and batches
- **Edit controls follow each apiary's role** — in the all-apiaries view, hives and inspections from an apiary you can only view no longer show edit buttons, and those from apiaries you edit do
- **Queen transfer between apiaries** — move a queen to a hive in any apiary you own or edit; the transfer dialog groups target hives by apiary

### Swarm Management Tools

- **Pagden and artificial swarm methods** join the Demaree method in the public tools, with a shared planner and step-by-step layout (PR #200)

### Inspections

- **Customisable table columns** — choose which columns the inspections table shows, with new toggleable Notes and Actions columns and cleaner row actions (PR #201)
- **Faster date/time entry** — new inspections default to the last used time, and a **Now** button sets the current moment (PR #209)
- **Richer frame counters** for the brood nest, plus a fixed weather autofill (PR #198)
- **Manual hive weight capture** — record weighings during an inspection, per box and side, in your preferred unit; weights show on the inspection detail page and as a trend chart on the hive page (PR #218), and a **Weighing** chip in the inspections table's Actions column shows when readings were taken (PR #221)
- **Camera input** for inspection photos, and a clear message when a photo cannot be attached (PR #229)

### Feeding

- **Custom feed types and sugar-aware feeding** — define your own feeds (for example a commercial invert syrup) with density and sugar content under Settings, enter amounts in g, kg, ml or L with live conversion, record extra dilution water, and see the sugar mass of every feeding on the inspection, timeline and reports; the hive feeding chart no longer mixes ml and g as if both were kg (PR #223)

### Treatments

- **Treatment product catalog** — 12 built-in products (VarroMed, Api-Bioxal, Apivar, Apiguard, MAQS and more) with their active ingredients, plus your own custom products with composition, density and withdrawal period; the inspection treatment action picks from the catalog and can record mite counts before and after for efficacy. The hive page shows applied active-ingredient totals and withdrawal status, and the reports page sums them per apiary (PR #225)

### Colony Splits

- **Split a colony in one step** — a wizard on the hive page moves brood frames into a new hive (optionally in another apiary), records where the queen went, writes a paired entry on both timelines, links daughter to mother with provenance badges, and schedules a requeening reminder; a split can be undone from the timeline while the daughter has no records of its own (PR #220)

### Queens

- **Breeding line, lineage and traits** — record breeder, line, mother queen (with links to her daughters and a "Rear daughter" shortcut), mating type, station and date, notes, and 1–5 ratings for gentleness, hygiene, swarm resistance and honey production; the queen pages were refreshed and gained a delete action (PR #256)
- **Virgin queens** — a new Virgin status for a hive's new queen, optional queen cell capped and emerged dates, a countdown to emergence and the date to look for eggs on the queen page, and an alert to check for eggs three weeks after she emerged (PR #258)
- **Queen pages match the hive page** — the queen page has the same header and action sidebar as the hive page, and the queens list gained search, clickable rows and an action sidebar (PR #259)

### Hive Status History

- **Status changes are recorded as timeline actions** — changing a hive's status (for example to dead or sold) creates an action with the previous and new status, visible in the hive timeline and inspection actions (PR #217)
- **Permanently delete a hive** — next to archiving, Manage Hive can now delete a hive with all its inspections, queens and files, after typing its name to confirm (PR #255)

### HiveHub & HiveScale

- **HiveHub rebrand** with a modular dashboard (PR #197)
- **Per-hive humidity, acceleration and air pressure** readings (PR #195)
- **Temperature compensation, localisation, named scales** and diagram fixes (PR #194)
- **Reorganised HiveHub page** — Overview, Inspections, Audio, Health and Setup tabs; cards for every hive (up to 18) with weight, 24 h change, climate, traffic and alerts; HiveHeart spectrum and daily max weight widgets; custom date ranges, CSV per chart, and faster long ranges (PR #236)
- **Inspection mode** — start and stop it per hive with a note, see past windows shaded on the charts, and get a prompt to start it from HivePal inspections of a linked hive (PR #236)
- **Hive links** — name all 18 slots and link each to a HivePal hive; linked hives show a HiveHub card on their hive page (PR #236)
- **Audio recordings** from HiveInside nodes, a Health tab for hub and sensor status, per-node firmware relays, remote setup access point, NDJSON data export and claim-code-protected range delete (PR #236)
- **Alert emails** — HiveHub insight alerts (swarm, queenless, robbing and more) are emailed when new or escalating, with a chosen minimum severity; replaces the old weight-drop swarm alert (PR #236)

### Dashboard

- **Refreshed dashboard and apiary pages** — collapsible dashboard sections, hive cards showing score, strength and feeding progress, a choice of how hive photos are shown (banner, side or hidden), clearer activity timeline entries, and a confirmation before deleting a todo; UI components updated to the latest shadcn versions along with the date picker and charts (PR #247)

### Sign-in

- **Single sign-on with OpenID Connect** — sign in through an OIDC provider such as Authentik; existing accounts are matched by email (PR #237)

### Settings

- **First day of week and 12h/24h time format** are now user preferences, applied across calendars, the inspection form and the inspections table (PR #207)

### Todo List

- A simple todo list, surfaced on the hive detail page

### App Updates

- **PWA update prompt** — the app now offers a deployed update instead of staying on a cached build (PR #227)

### Miscellaneous

- Hive settings and form fully translated
- Public pages refresh
- Frontend moved to React Router framework mode; public pages are prerendered by React Router instead of a custom pipeline (PR #238)
- Playwright smoke suite for preview deployments (PR #244)
- Preview deployments can seed a demo account with apiaries, hives and a season of inspections (PR #257)
- Component tests moved to the Playwright stories model, so Playwright can be upgraded again (PR #248)

## 🐛 Bug Fixes

- The whole hive card on the dashboard opens the hive, photo included; inspection warnings are translated and the card shows sugar in your weight unit and older inspection dates in your date format (PR #260, #162)
- Hive edit form no longer fails silently with a dead save button, and saves hives in non-active statuses (PR #211)
- Hive boxes render at proportional real-world heights, so Dadant honey supers and feeders no longer look the same size as brood boxes (PR #206)
- Secure cookies fixed for production deployments
- Editing a colony split works again after hive status changes became timeline actions (PR #245)
- HiveHub SD import asks for confirmation before importing a file recorded by a different hub (PR #236)

## 🛠️ Self-Hosting

- Prometheus metrics moved to a dedicated internal server on `METRICS_PORT` (default 9100), off the public `/api` surface
- Grafana Faro and Alloy added for frontend monitoring
- Faster Docker image builds
- HiveHub variables renamed to `HIVEHUB_API_BASE_URL` / `HIVEHUB_SERVICE_API_KEY` (the `HIVESCALE_*` names still work); HiveHub needs `HIVEPAL_JWT_SECRET` set to HivePal's `JWT_SECRET`. Hive links, export/delete, remote setup access point and relay status need HiveHub server 0.6.0 or newer (PR #236)
- Dependency refresh: NestJS 12, Vite 8, Vitest 5, ESLint 10, Prisma 7.10, better-auth 1.7, Sentry 11, lucide 1, i18next 26. Node 22.12 or newer is now required (the `node:22` images already are) (PR #243)
- SSO: set `OIDC_ISSUER`, `OIDC_CLIENT_ID` and `OIDC_CLIENT_SECRET` to enable it; the redirect URI is `<BETTER_AUTH_URL>/api/auth/callback/<OIDC_PROVIDER_ID>` (default provider id `authentik`). `OIDC_ALLOW_SIGNUP` controls whether unknown users are created, and `DISABLE_LOCAL_LOGIN` makes SSO the only sign-in method (PR #237)
- Mail: nodemailer 10 validates the SMTP server's TLS certificate by default. If your SMTP server uses a self-signed certificate, set `tls.rejectUnauthorized: false` in the SMTP transport options

## 🌍 Translations

- **German completed and standardised** — every English key now has a German translation, the app consistently addresses users with the formal *Sie*, and *Durchsicht* replaces *Inspektion* throughout, matching German beekeeping usage (PR #204)
- **"Deutsch (du)"** — an optional informal German, selectable in the language switcher; it overlays only the strings that differ from the formal default and never produces its own public URLs (PR #214)
- **Russian** added as a new language (PRs #234, #235)
- Continued Weblate contributions across supported languages
