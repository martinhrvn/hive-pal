# Version v0.20.0 Swarm Season

**Released:** Unreleased

## 🚀 What's New

### Swarm Management Tools

- **Pagden and artificial swarm methods** join the Demaree method in the public tools, with a shared planner and step-by-step layout (PR #200)

### Inspections

- **Customisable table columns** — choose which columns the inspections table shows, with new toggleable Notes and Actions columns and cleaner row actions (PR #201)
- **Faster date/time entry** — new inspections default to the last used time, and a **Now** button sets the current moment (PR #209)
- **Richer frame counters** for the brood nest, plus a fixed weather autofill (PR #198)
- **Camera input** for inspection photos, and a clear message when a photo cannot be attached (PR #229)

### Hive Status History

- **Status changes are recorded as timeline actions** — changing a hive's status (for example to dead or sold) creates an action with the previous and new status, visible in the hive timeline and inspection actions (PR #217)

### HiveHub & HiveScale

- **HiveHub rebrand** with a modular dashboard (PR #197)
- **Per-hive humidity, acceleration and air pressure** readings (PR #195)
- **Temperature compensation, localisation, named scales** and diagram fixes (PR #194)

### Settings

- **First day of week and 12h/24h time format** are now user preferences, applied across calendars, the inspection form and the inspections table (PR #207)

### Todo List

- A simple todo list, surfaced on the hive detail page

### App Updates

- **PWA update prompt** — the app now offers a deployed update instead of staying on a cached build (PR #227)

### Miscellaneous

- Hive settings and form fully translated
- Public pages refresh

## 🐛 Bug Fixes

- Hive edit form no longer fails silently with a dead save button, and saves hives in non-active statuses (PR #211)
- Hive boxes render at proportional real-world heights, so Dadant honey supers and feeders no longer look the same size as brood boxes (PR #206)
- Secure cookies fixed for production deployments

## 🛠️ Self-Hosting

- Prometheus metrics moved to a dedicated internal server on `METRICS_PORT` (default 9100), off the public `/api` surface
- Grafana Faro and Alloy added for frontend monitoring
- Faster Docker image builds

## 🌍 Translations

- Continued Weblate contributions across supported languages
