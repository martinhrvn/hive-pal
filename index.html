Two ways to run it

Use hivepal.app

Sign up and start recording straight away. The hosted app runs the same open-source code, and you can export your data at any time.

Open the appQuick start walkthrough

Run it yourself

One Docker image with the API and web app, plus a PostgreSQL database. Two containers, one compose file.

# docker-compose.yaml: the app and a PostgreSQL database
services:
  app:
    image: ghcr.io/martinhrvn/hive-pal:latest
    ports: ['80:3000']
  postgres:
    image: postgres:14

$ docker compose up -d
